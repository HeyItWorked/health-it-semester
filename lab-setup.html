Lab setup

All run on 31 Oct 2026

These are the lab's five commands. Do the prework first: it installs the tools and downloads the two jars.

docker run -d --name hapi -p 8080:8080 hapiproject/hapi:latest
docker run -p 8443:8443 -p 6661:6661 openintegrationengine/engine
java -jar synthea-with-dependencies.jar -p 100 --exporter.fhir.use_us_core_ig=false
mllp_send --loose -f adt.hl7 -p 6661 localhost
java -jar validator_cli.jar p.json -version 4.0.1 -ig hl7.fhir.ca.baseline

Check that the FHIR server answers; it needs about a minute to start. This should print "4.0.1":

curl -s localhost:8080/fhir/metadata | jq .fhirVersion
  • Loading patients. POST Synthea's bundles to HAPI in this order: hospitalInformation*, practitionerInformation*, then the patient bundles. Week 0 shows why the order matters.
  • The Synthea flag. --exporter.fhir.use_us_core_ig=false gives plain FHIR R4. Week 0 uses it. Weeks 1, 2 and 4 leave it out, because they need the clinical notes and the US Core profiles.
  • OIE. Log in as admin / admin. That is for the lab only.
  • mllp_send comes with pip install hl7.
  • Canadian patients. Put synthea-international's ca/ first on the classpath; week 1 shows the command.
